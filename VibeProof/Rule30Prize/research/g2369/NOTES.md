# Automaton group 2369 is rule 30's transducer group, and it is locally-finite-by-ℤ

2026-10-17. Status: a complete proof on paper, with its non-standard inputs in Lean (kit
`equivalents/Rule30Equivalents/AutomatonGroup.lean`) and every claim below checked by computation.

## 1. Identification

Read from the least significant bit, rule 30's integer step Φ(x) = x ⊕ (2x ∨ 4x) is a Mealy
automaton whose state remembers the two previous input bits. Minimized, it has three states:

    c = (c, a),   a = σ(b, a),   b = σ(c, a),     c = Φ,

with g(xw) = π_g(x) g|_x(w). Up to the 24 symmetries (renaming states, swapping the letters,
inverting), this is automaton **2369** of the classification of groups generated by 3-state automata
over a 2-letter alphabet [BGK+08]. `autnum.py` computes the numbers of all 24 variants; the least is
2369, and the same code gives 739 for the paper's own example.

The classification records G2369 as:
- self-replicating;
- not contracting;
- with relators (a⁻¹b)², (b⁻¹c)², [a,b]², (a⁻¹c)⁴, …;
- with |G/St(n)| = 2^{0,1,3,7,13,25,47,90,176} for n = 0, …, 8;
- with the "Group" field blank: its isomorphism type is not identified.

Its proof that a has infinite order is the growth of rule 30: the orbit of 10^∞ is infinite because
the nonzero prefix grows by 2 at each step. The paper does not mention rule 30.

**The states are frozen-boundary steps.** Let Φ_s(x) = x ⊕ (2x ∨ 4x ∨ s). This is one step of rule 30
on the half-line, with the two cells beyond the edge frozen:
- c = Φ_0, white-white;
- b = Φ_1, white-black;
- a = Φ_3, black-anything.

In Lean, `PhiS_zero`, `PhiS_one` and `PhiS_three` show

    b = σ ∘ Φ,   a = τ ∘ Φ,

where σ(y) = y ⊕ 1 and τ(y) = y ⊕ (3 if y is even, else 1). As tree automorphisms, σ = σ(1, 1) and
τ = σ(σ, 1). Both change only the two lowest bits, and ⟨σ, τ⟩ = Aut(T₂), the dihedral group of
order 8. So

    G2369 = ⟨Φ, σ, τ⟩ = ⟨Φ, Aut(T₂)⟩.

In the generators c, h = b⁻¹c and k = a⁻¹b the recursion reads c = (c, chk), h = σ(kh, hk),
k = (h, 1), and D = ⟨h, k⟩ = c⁻¹ Aut(T₂) c.

## 2. Structure theorem

**Theorem.** Let F = ⟨σ, τ⟩. Let L be the group generated by the conjugates Φⁿ f Φ⁻ⁿ, for n ≥ 0 and
f ∈ F, and let N be the normal closure of F in G = G2369. Then:

1. Every element of L is finitary. L is a locally finite 2-group, and Φ L Φ⁻¹ ⊆ L.
2. N is the ascending union ⋃_{m≥0} Φ⁻ᵐ L Φᵐ. It is an infinite, locally finite 2-group.
3. G = N ⋊ ⟨Φ⟩ and G/N ≅ ℤ. Equivalently, G is the ascending HNN extension of L by the injective
   endomorphism x ↦ Φ x Φ⁻¹.
4. G is elementary amenable, has exponential growth, and is not finitely presented.

**Proof.**
- **The light cone** (`testBit_orbit_eq_of_agree`). Bit i of Φ(x) reads only bits i, i−1 and i−2
  of x. So if x and y agree on all bits ≥ d, then Φⁿ(x) and Φⁿ(y) agree on all bits ≥ d + 2n.
- **Forward conjugates are finitary** (`conj_finitary`). Let f be finitary of depth d. For any x,
  put y = Φ⁻ⁿ(x). Then Φⁿ f Φ⁻ⁿ(x) = Φⁿ(f(y)) agrees with Φⁿ(y) = x on all bits ≥ d + 2n. So
  Φⁿ f Φ⁻ⁿ is finitary of depth ≤ d + 2n.
  - Since σ has depth 1 and τ depth 2, every generator of L is finitary. Hence L lies in the group of
    finitary automorphisms.
  - That group is locally finite: finitely many finitary elements lie in some Aut(T_D), which is
    finite and a 2-group. So L is a locally finite 2-group.
  - Conjugation by Φ maps the generator with index n to the one with index n + 1, so Φ L Φ⁻¹ ⊆ L.
- **N.** G = ⟨F, Φ⟩, so the normal closure of F is generated by the Φⁿ F Φ⁻ⁿ for n ∈ ℤ. It is
  therefore ⋃_m Φ⁻ᵐ L Φᵐ, an ascending union of copies of L, hence locally finite.
  - N is infinite. Φⁿ σ Φ⁻ⁿ sends 0 = Φⁿ(0) to Φⁿ(1), row n of the seed, whose bit 2n is set
    (`conj_sigma_depth`). So these conjugates have depth exactly 2n + 1 and are pairwise distinct.
- **Φ has infinite order** (`TFunctionCycles.lt_iterate_Phi`), so Φᵏ ∉ N for k ≠ 0. G/N is
  generated by the image of Φ, so it is ≅ ℤ. An ascending union of the iterated conjugates of L is
  exactly the base of the ascending HNN extension.
- **Elementary amenable.** Locally finite groups are directed unions of finite groups, and the class
  of elementary amenable groups is closed under extensions.
- **Exponential growth.** By Chou [Cho80], an elementary amenable group has either polynomial growth
  or exponential growth. Polynomial growth would make G virtually nilpotent, and then every torsion
  subgroup of G is finite. N is an infinite torsion subgroup, so the growth is exponential. This
  matches the classification's growth values 1, 7, 33, 143, 602, 2514.
- **Not finitely presented.** If G were finitely presented, Bieri and Strebel [BS78] would make G an
  HNN extension over a finitely generated base B ≤ N, and B would be finite.
  - If both associated subgroups equal B, the kernel N would be B, which is finite: a contradiction.
  - Otherwise the kernel is a tree product of copies of B, which contains elements of infinite order.
    That contradicts N being torsion. ∎

**Credit.** The argument is the one Silva and Steinberg give for reset automata [SS05], whose groups
are locally-finite-by-cyclic. The automaton here is not a reset automaton but 2-definite: its state
after two letters does not depend on the start. The same proof shows that every group generated by
an invertible definite automaton is locally-finite-by-cyclic. In one form of that proof, all states
differ from one state s₀ by finitary maps, and conjugation by s₀ⁿ preserves finitary maps because of
finite memory. I found no source that states this for definite automata or that identifies G2369.

## 3. Computations

**Exact word problem** (`g2369.py`). Every element is a normal form d₀ c^{±1} d₁ ⋯ c^{±1} d_ℓ with
dᵢ ∈ D. Sections never add a c-letter, so deciding whether a word is trivial is a finite search.
- `g2369_e1.py`: the classification's relators are trivial and the non-relations are not.
- `g2369_e2.py`: no normal form with ℓ ≤ 3 is trivial; up to three Φ-letters, G looks like the
  free product D ∗ ℤ. cⁿ D c⁻ⁿ ∩ D = 1 for n ≤ 3.
- `g2369_e3.py`: all twelve trivial normal forms with ℓ = 4 (and d₀ = 1) have exponent sum 0. Each is
  a commutation between an element supported on the 0-subtree and one supported on the 1-subtree.
  For example, k = (h, 1) and hkh = (1, khk), and Φ preserves the two subtrees.
- `g2369_e4.py`: σ = bc⁻¹ and τ = ac⁻¹ have depths 1 and 2. cⁿσc⁻ⁿ and cⁿτc⁻ⁿ have depths
  2n + 1 and 2n + 2 for n ≤ 5. c⁻¹σc is not finitary.

**GAP** (`g2369_gap.wls`, `g2369_filtration.wls`). These use WolframInstitute/GAPLink 0.2.3 with
GAP 4.16.1, core and required packages only, without AutomGrp. G_n is the group that ⟨Φ, σ, τ⟩
induces on the 2ⁿ words of length n, and N_n is the normal closure of ⟨σ, τ⟩ in G_n.

| 1 | 1 | 1 | 1 | 1 | 2 |
| 2 | 3 | 3 | 1 | 2 | 2, 2 |
| 3 | 7 | 6 | 2 | 2 | 2, 2, 2 |

- The orders agree with the classification for n ≤ 8. Level 9 is new.
- The index [G_n : N_n] grows slowly (4 at levels 5 to 8, then 8), consistent with G/N ≅ ℤ.

The finitary filtration Mⱼ = ⟨Φⁱ σ Φ⁻ⁱ, Φⁱ τ Φ⁻ⁱ : i ≤ j⟩ ≤ Aut(T_{2j+2}):

| j | depth | log₂\|Mⱼ\| | log₂\|Aut(T_{2j+2})\| | abelianization | nilpotency class |
|---|---|---|---|---|---|

| 3 | 8 | 174 | 255 | (ℤ/2)⁸ | 34 |

- |Mⱼ| = |N_{2j+2}|: at level 2j + 2 the image of N is generated by the conjugates of depth
  ≤ 2j + 2.
- The nilpotency classes 2, 5, 13, 34 are every other Fibonacci number (F₃, F₅, F₇, F₉). This is an
  observation from four values, not a claim.

## 4. Open

- The isomorphism type of L, as a direct limit of the finite 2-groups Mⱼ.
- Whether the nilpotency classes of Mⱼ continue as F_{2j+3}.
- The Hausdorff dimension of the closure of G, where log₂|G_n| / (2ⁿ − 1) = 0.69 at n = 8 and
  0.68 at n = 9.
- Whether this structure says anything about the seed's orbit. Problem 1 asks about one point: the
  center column is the root bit of the section of Φᵗ at the vertex 10^{t−1}. An amenable G with
  locally finite N does not seem to constrain that orbit.

## 5. Does the group constrain finite-seed orbits?

No. Every fact above is uniform in the starting point and concerns fixed bit positions or the whole
group. The center column reads bit t at time t. In group terms, c(t) is the root bit of the section
of Φᵗ along the seed's path. That section is ℓₜ Φᵗ with ℓₜ ∈ L finitary of depth up to 2t, and the
finite groups Mⱼ that ℓₜ lives in grow without bound.

**Exact reduction.** Φ fixes the lowest bit and continues as the state a = τΦ, so
Φ(2y + 1) = 2·a(y) + 1, checked for y < 2¹⁶. Hence c(t) = bit t − 1 of aᵗ(0), checked for t ≤ 3000.
The center column of the seed is the column at distance t − 1 from a black wall, read on the
half-line that starts white.

**Testing the natural strengthening** (`frozen_readouts.py`, `m1_readouts.py`). A group-level
argument cannot single out Φ among the elements ℓΦ, ℓ ∈ L. So it would have to show that their
diagonal readouts t ↦ bit t of (ℓΦ)ᵗ(a) are all aperiodic.
- **The 8 frozen-boundary steps fΦ, f ∈ Aut(T₂).** For seeds 1, 3 and 5 and t < 4000, there is no
  eventual period up to 600, and every density is about 0.5.
- **All 4096 forcings ℓ ∈ M₁ (depth 4), seed 1, t < 1500.**
  - 384 readouts are eventually periodic. Each is degenerate: ℓ undoes Φ on the seed, so the orbit
    of 1 stays at 1.
  - All 3712 forcings whose orbits keep growing have readouts with no eventual period up to 300.

**Conjecture.** For every finitary ℓ in G2369 and every finite seed a whose orbit under ℓΦ is
unbounded, the diagonal readout of ℓΦ on a is not eventually periodic. This contains Problem 1 and
FinConf (ℓ = 1).
- What makes it interesting: the family {ℓΦ} is closed under sections. The section of ℓΦ is ℓ′Φ with
  depth(ℓ′) ≤ max(depth ℓ − 1, 2), so deep sections fall into the 8 frozen-boundary steps. Taking
  sections moves the seed's bits into the forcing.
- Why it does not close by induction: G2369 is not contracting, and sections of powers produce
  readouts along lines of slope 2 and more. For example, a has nontrivial root action, so aᵗ splits
  into (ab)^{t/2}.

## 6. The frozen-boundary conjecture, more deeply

Lean: kit `equivalents/Rule30Equivalents/FrozenBoundary.lean`. Scripts: `classify_drivers.py`,
`classify_pairs.py`, `classify_pairs2.py`.

**Edge decoupling** (`testBit_step_add_two`, `testBit_step_zero`, `testBit_step_one`). Write the 8
steps as g = f ∘ Φ, where f flips bit 0 if α, and bit 1 if β (bit 0 = 0) or γ (bit 0 = 1).
- In the bulk, bit k + 2 of g(x) is x_{k+2} ⊕ (x_{k+1} ∨ x_k), which is rule 30.
- The two edge cells evolve on their own: x₀ ↦ x₀ ⊕ α, and x₁ ↦ x₁ ⊕ x₀ ⊕ (β or γ). Their period
  divides 4.
- The bulk sees the edge only through the drivers x₁ ∨ x₀ (into bit 2) and x₁ (into bit 3).
- So every instance is rule 30 on a half-line bounded by a diagonal that carries periodic data.

**Which boundaries are genuine.** In rule 30 the cells beyond a speed-1 line evolve on their own.
A frozen pair (p, q) beyond the edge is genuine only if some rule-30 right half keeps it constant.
- (0, 0) is genuine: it is the white right half of a finite configuration, and the step is Φ.
- (1, 0) is genuine: it is the right edge of a finite configuration one cell beyond the frame, and
  the step is the black wall a.
- (0, 1) is not genuine: b's boundary cannot be held by any right half. But b still embeds into
  finite seeds through ι(y) = 4y + 2(y mod 2) + 1, which couples edge bit 1 to bulk bit 2
  (`Phi_iota`).

Hence `genuineFrozen_iff_finConfRows`: **on the three genuine frozen boundaries Φ, b, a, the
conjecture is equivalent to FinConf.**

**Classification of all 32 (step, edge state) pairs** (`classify_pairs.py`). The criterion: does
some pair of consecutive diagonals of the orbit equal, as a periodic sequence up to a time shift, a
pair of consecutive diagonals of a finite seed's Φ-orbit? Above such a pair the two arrays are the
same rule-30 array, so the readouts are the same readout problem.
- Φ, a, b, (0,0,1), (0,1,0) and (0,1,1) reduce on every residue mod 2¹⁰, at depth ≤ 2.
- (1,0,1) reduces on 11/16 of the residues mod 2¹⁰ and mod 2¹². The rest is the white-blinking
  edge, where x₁ = 0 and x₀ alternates.
- (1,1,1), which is Φ followed by complementing the two edge cells, reduces on no residue (target
  depth ≤ 10, finite-seed depth ≤ 15).
- An apparent match of (1,1,1) with complemented finite-seed pairs is spurious. Complementing turns
  rule 30 into rule 135, so such a match does not propagate up the array.
- Conclusion: the content of the conjecture beyond FinConf lives on edge rules that no rule-30
  boundary produces.

**Proved for all 8 steps** (period 1 and adjacent Jen).
- The readouts obey rule 30's column relations in the bulk (`readout_left`, `readout_right`).
- Once x ≥ 4, the top bit rises by exactly 2 per step (`iterate_top`), which plays the role of
  the left edge.
- Jen's argument then gives `not_adjacent_readouts`: no two adjacent readouts are both eventually
  periodic.
- Condrey's argument gives `frozenBoundary_period_one`: for every step and every seed with an
  unbounded orbit, no readout is eventually constant. This includes the irreducible step (1,1,1).

So the conjecture now stands where FinConf stood: period 1 is proved uniformly, and period 2 is
the frontier.
