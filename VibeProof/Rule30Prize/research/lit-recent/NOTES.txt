[A] Nersissian 2609.25077 "Diagonal Periods and Newton Supports of Rules 30, 86 and 135" (40pp, Sept 2026)
 conventions: b(m,n)=A(n,n-m+1) = our R_{m-1}(n); c(t)=b(t+1,t).
 Newton support: d(n)=XOR_{r in S} C(n,r) mod 2 = parity #{r in S : r subset-of n (bitwise)}.
 Rule 30: S_m = Inc(S_{m-1} Δ S_{m-2} Δ (S_{m-1} ⊛ S_{m-2})), S_1={0}, S_2={1}; ⊛ = OR-convolution, Inc = +1 shift.
 Thm (first contact) min S_m = floor(m/2).  Thm (Fibonacci ceiling) max S_m <= F_{m+1}-1.
 Thm exactper: finite nonempty S, k minimal with S ⊆ [0,2^k): least period exactly 2^k.
 Thm unbounded: right diagonal least period P_m = 2^{ceil log2(max S_m +1)} >= floor(m/2)+1; each record of running max doubles.
 Remark: c(t) = b(t+1,t) moving depth -> theorem cannot be applied to center column.
 Rule 86 (mirror; = our LEFT side): D_m(t+1) = D_{m-2}(t) xor (D_{m-1}(t) or D_m(t)).
  Thm driver: u,v ev. periodic common period P, v(t0)=1 for t0>=tau => w ev. periodic, period | P.
  Thm parity: v ev. 0 => least period of w is pi (sigma=0) or 2pi (sigma=1), sigma = parity of u over a period.
  Lemma pairperiod: Q_m = max_{j<=m} pi_j = max(pi_{m-1}, pi_m) (backward recurrence).
  Cor criterion: record iff D_{m-1} ev. zero and D_{m-2} has odd period parity (= Rowland Prop 2 / Wolfram NKS p.871).
  Prop transient: D_m(t)=0 for t<m/2; if periods <= P and tail nonzero then tau_m >= m/2 - P.
  Thm profile (KEY TECHNIQUE): m+2 <= 4^{Q_m}, i.e. Q_m >= (1/2) log2(m+2). Proof: backward map B on pairs of
   P-periodic profiles (abs. phase), zero pair fixed, Sigma_0=(0,1) != (0,0) => Sigma_{-1..m} distinct => pigeonhole.
 Records: D-convention 0,3,8,29,400 (A364239: 1,4,9,30,401,87868); proposed next 2107985256 not established.
 Center column subsection: only finite certificate: words (c(2^a j + r))_{1<=j<=31}, a<=12, r<2^a all 8191 distinct
  (prefix 131072) => any LSD-first 2-DFAO generating c needs >= 8191 states. No nonperiodicity claim.
 Kopra 2023 TCS cited as giving width-2 trace aperiodicity.

[D] Kopra, "Rapid left expansivity, a commonality between Wolfram's Rule 30 and powers of p/q", TCS 946 (2023) 113668,
 arXiv 2202.13809 ("A natural class of CA containing fractional multiplication automata, Rule 30, and others").
 Def left expansive (h,d,w); left permutive (m,n) => left expansive (0,1,m+n). left spreading speed s; rapidly LE: s < 1/h.
 Lemma expPer: width-w trace at [i,i+w-1] ev. p-periodic preperiod c => trace at [i-1,i+w-2] ev. p-periodic preperiod c+h.
 Thm aperThm: F rapidly LE width w, x number-like (nonzero, zero far left) => Tr_{[i,i+w-1]}(x) NOT ev. periodic, any i.
   (Rule 30: w=2: no two adjacent columns both ev. periodic, for EVERY number-like x; generalizes Jen 1990 Prop 3.)
 Thm: frac(F^t x) = frac(x) for finitely many t; Thm: (frac(F^t x))_t has infinitely many limit points.
 Problem (open): width-1 trace of single seed under rule 30. BARRIER: Rule 90 is rapidly LE but its single-seed center
   column is eventually periodic (1,0,0,0,...), so width-1 aperiodicity cannot follow from rapid left expansivity alone.

[E] Rowland 2006 "Local Nested Structure in Rule 30", Complex Systems 16(3) 239-258.
 Rule 86 = range [2,0] (left-justified mirror) right bijective version. Prop 1: rightful row has at most one infinite rightful history.
 Lemma 1: right bijective range [d,0]: if R,S first differ at M then (f^t R)(M) != (f^t S)(M) for ALL t (forward and backward).
 Lemma 2: right bijective k-color range [d,0]: columns m-d..m-1 periodic (pure) => column m periodic, period | l(k) lcm(...),
   l(k)=lcm(1..k).   => rule 30 right diagonals purely periodic with power-of-2 periods.
 Thm 1: f^{l(k)^n} R -> R (bitwise) for rightful R with infinite rightful history.
 a(n) = Lambda_I(2^n) = number of right diagonals with period | 2^n: 1,3,4,6,7,9,15,16,24,25,27,29,34,... (A094605?)
 Conj 1: central rows R with white tails having nonperiodic iota_R are exactly f^r I. Conj 2, Conj 3 (irreducibility).
 Sec 5: Prop 2 (Wolfram NKS p.871): left-diagonal period doubling iff left neighbor diagonal ev. white and next one has odd
   parity per block; holds for any rightful initial row. Lemma 3 (long-term effect iff column m-1 white for t>=t0).
 Remark: first column where left side could depend on initial condition: 53209 (col 53208 ev. white, col 53207 even parity).
